# VeilTender

**报价始终密封,只公开价格。**

面向 AI Agent 的保密密封投标任务拍卖,基于 FHE 在密文上计算。

[在线演示](https://shentonyan.github.io/veil-tender/) · [English](README.md) · [机制说明(英文)](docs/MECHANISM.md)

</div>

发布者托管一笔公开预算,Agent 提交**加密**报价。合约在密文上把所有报价折叠成"最低分、次低分、赢家序号",
全程不对任何密文做分支判断。截止后只解密(赢家序号,次低分)并在链上验证。赢家按 Vickrey 式门槛价获得报酬。
单个报价和落选者的出价不会被逐一解密;代币余额和转账金额通过 ERC-7984 保持加密。

为 ETH Shenzhen 2026 黑客松而做(方向:Agent 与机器经济、隐私与安全)。

> **当前状态:** 原型。30 项测试在本地 FHEVM mock 上通过(含与明文参考实现的随机差分测试)。**尚未部署到公共网络**,
> 未经审计。

## 先看演示

`web/` 是一个静态双语(EN / 中文)演示站,无需构建(唯一的外部请求是 Google Fonts,带系统字体回退)。
它把一场拍卖从头到尾走完:

- 六步引导式回放,素材是合约在本地 FHEVM mock 上的一次真实运行(`web/transcript.js`,由 `npm run demo` 生成),
  每一步都拆成**链上·所有人可见**与**密封·从不以明文出现**两栏,包括该次运行真实产生的密文句柄;
- 试玩区:改预算、真实成本、handicap 和报价策略,看中标结果与收益曲线变化。赢家的收益曲线是一条平线:
  虚报并不会让你赚得更多,这正是这条规则的要点;
- "谁能看到什么"对照表,以及每份报价的 FHE 折叠代码。

试玩区运行的是规则的明文副本 `web/mechanism.js`。`test/webRule.ts` 用 5000 个随机拍卖把它与合约测试所用的同一份
明文参考实现做差分比对。需要说明:网站是**规则的模拟**,浏览器里并不做 FHE;回放来自 mock,不是 Sepolia。

直接打开 `web/index.html`,或 `npx serve web`。在仓库 Settings → Pages 里把 Source 设为 GitHub Actions 后,
工作流会自动发布。

## 为什么值得做

二价(Vickrey)拍卖让如实报价成为占优策略,但它在现实中出了名地罕见——Rothkopf、Teisberg 与 Kahn(1990)
给出的原因是:看得到报价的拍卖人可以作弊,而投标者害怕暴露成本。公链把这两个问题放大而不是解决:每份待确认
报价都可读,commit\u2013reveal 方案只要有落选者拒绝揭示就会卡死。在 FHE 下计算拍卖,把拍卖人和揭示阶段一并
移除。对机器间采购——Agent 雇佣 Agent,挂牌价暴露利润、逐一议价无法规模化——这让教科书机制第一次变得可部署。

## 规则

- 超出公开预算 `B` 的报价被静默中和(不 revert,因此有效性不泄露);
- `score = 报价 + handicap`,handicap 是创建招标时固定的**公开**数值(例如由链下信誉摘要得出),全为 0 时就是普通的
  最低价中标反向拍卖;
- 最低分中标,完全平局时先提交者中标;
- 赢家获得 `min(次低分 − 自身 handicap, B)`;只有一个有效报价时获得 `B`(预算即公开保留价);
- 在私有成本、风险中性、无串谋、保证金与报价无关的假设下,如实报价是弱占优策略(Vickrey 1961;Myerson 1981)。
  假设与"不声称什么"见 [docs/MECHANISM.md](docs/MECHANISM.md)。

| | 公开 | 保密 |
|---|---|---|
| 预算、截止时间、保证金、评审人 | 是 | |
| 谁参与了投标、各自 handicap | 是 | |
| 赢家与成交价 | 是 | |
| 每一个单独的报价 | | 是,从不解密 |
| 落选者的价格 | | 是(仅揭示一个无归属的次低分) |
| 代币余额与转账金额 | | 是,在保密代币账本上 |

注意:成交价等于某个落选报价对应的值,只有两个投标者时可通过排除法归属到具体的人。

## 运行

需要 Node 20 或更新版本。

```powershell
npm install
npm test        # 本地 FHEVM mock,无需联网
npm run demo    # 四个 Agent、一场加密拍卖;会重写 web/transcript.js
```

如果环境无法下载原生 Solidity 编译器:`$env:SOLCJS = "1"; npm test`(PowerShell)。

Sepolia 路径使用同一份演示代码,但**尚未实测**:解密延迟、单区块 FHE 计算上限和真实 gas 都未测量。

## 局限

- 原型、未审计、仅在 mock 上测试;没有公共网络部署;
- 无法防止串谋,也不防女巫攻击(保证金与每地址一次报价只抬高成本);
- 参与者与成交价是公开的;
- 默认由发布者担任评审人,可能拒收合格交付,评审人在投标前即固定并可见,投标者可据此定价或指定中立评审人;
- handicap 是受信输入,如实报价的结论以其外生为前提;
- 依赖 Zama 解密网络的阈值诚实假设,以此替代对拍卖人的信任;
- 预算小于 2^40 基本单位,每个招标最多 255 个投标者;
- 未集成 ERC-8183 / x402 / Chainlink。
